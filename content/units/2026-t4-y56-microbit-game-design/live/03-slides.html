Beat my score!

10 seconds. Smash A.

Learning Intention

To use variables to keep score and to control when our game is running.

Success Criteria: I can

use a variable to count how many times a button is pressed. use a true or false variable so that presses only count while the game is running. test my game, find a problem, and fix it.

Think about it

What does the game need to remember?

Big idea

A variable holds one value.

Put something new in and the old value is gone.

Big idea

A flag is a variable that holds true or false.

The algorithm

At the start, score is 0 and the game is not running. B: score to 0, count down, game running. While running, A adds 1 to the score. After 10 seconds: not running, show the score.

Build it, then test it

Make B the START button. Make the game STOP by itself 10 seconds after GO. TEST IT: can you still score after TIME? FIX IT: presses only count while the game is running.

Look after the kit
