Intro to Jacdac

Remember

What is an input? What is an output?

Think about it

No battery. No screen. No brain.

How does the micro:bit know which one is which?

Learning Intention

To connect Jacdac modules to a micro:bit and code them so a button press makes a light turn on.

Success Criteria: I can

connect a Jacdac button and LED ring to my micro:bit using the Jacdapter. add the jacdac extension and the blocks for my modules in MakeCode. code my micro:bit so pressing the button lights up the LED ring. send my code to the micro:bit from the iPad and test that it works.

Your kit

Input: the button. Output: the ring.

Kit rules

Parts live in the tray, not on the table. Cables click in firmly. Battery pack off at pack up.

Is it broken? What's missing?
